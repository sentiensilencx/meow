# meow

I am going to redefine the scope of this random project I scribbled down here I don't even remember how long ago;

An alarm app. But instead of a normal alarm app, it is a *cute* alarm web-app (HTML) with a cat laying as a loaf on top of it. And the cat wakes up and falls asleep according to your alarm and consistently comments on how annoying you are.

I want to make this give off a cozy vibe, definitely inspired by [cozy.talk](https://cozy.talk/), which is probably inspired by [SerenityOS](https://serenityos.org/). I hope I can make the cat goofy, and funny. That the alarm goes off with a pleasant ring instead of that goddamn thunder chicken on ig. Going for a retro-ish, 90's ish, pixelated-ish aesthetic with it.

*Yeah*
